# Required Secrets

## erfan-resume-file

- Namespace: `web`
- Type: `Opaque`
- Required key: `erfan-resume.docx`
- Used by: `Deployment/erfan-resume`
- Must be recreated separately or managed through a secret-management system.

## erfan-resume-tls

- Namespace: `istio-ingress`
- Type: `kubernetes.io/tls`
- Generated by: `Certificate/erfan-resume-tls`
- Managed automatically by cert-manager.

## letsencrypt-prod-account-key

- Managed automatically by cert-manager.
- Referenced by: `ClusterIssuer/letsencrypt-prod`
